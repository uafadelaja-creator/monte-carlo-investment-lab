Open the daily scanner through a local HTTP server (for example `python3 -m http.server 8000` from this folder, then open `http://localhost:8000/daily.html`). It reads and verifies the existing GitHub data. Saved pairs and comparisons stay in this browser. The comparison uses the previous verified session this browser saw and may skip days between visits.

The optional walk-forward script requires numpy and pandas. Run `python walk_forward.py prices.csv AAA BBB CCC > results.csv` using adjusted daily closes and a universe documented before the first test period. Each 252-session formation window selects the highest-correlated pair and freezes its price fit for the following 63 sessions. Signals fill at the next close, and each fold ends flat. This is a separate baseline experiment with approximate weighted returns and hypothetical costs. It does not replicate the production scanner or model borrow availability.
